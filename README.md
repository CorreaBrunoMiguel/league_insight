# LeagueInsight Lab — Observatório & Previsor de Campeonatos

Projeto Orion focado em análise e previsão de resultados em campeonatos
nacionais de pontos corridos.

## Ciclo Orion (Pré-Implementação)

- `doc/00_semente_orion.md` — Semente: identidade, fenômeno, pergunta
  científica.
- `doc/01_genese_orion.md` — Gênese: visão, modelo conceitual, arquitetura alvo,
  ética.
- `doc/02_fundacao_orion.md` — Fundação: mapa de etapas, alinhamento e
  rastreabilidade.
- `doc/03_echocodex_orion.md` — Echo Codex: repositório vivo, branches, commits
  e integrações docs↔código.
